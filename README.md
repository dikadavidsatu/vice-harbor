**Neon Bay** — an original open-world crime game set in a fictional sun-soaked bay city at golden hour. Explore the city on foot or by car, steal cars and drive through live traffic, dodge pedestrians, raise a 5-star wanted level and outrun the police, fight through combat, and play five story missions for fixer Mara Voss — from a package pickup on the pier to a five-star escape to the safehouse. Includes a live minimap, HUD, start screen, localStorage saves, and fully synthesized WebAudio sound (engine, gunshots, sirens, synthwave music).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
